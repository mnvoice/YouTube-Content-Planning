# 진행자 기준 카드 3판 — Self-Refine과 사람 피드백 요약 학습

2판(`../moderator_criteria.md`)은 보존한다. 논문에서 확인한 내용과 확인하지 못한 범위는 2판과 같다
(두 논문 모두 본문 미확인, 저자 공식 자료와 검색 요약까지). 3판에서 달라진 것은 **어느 절차에 반영했는가**다.

## Self-Refine (Madaan 외, 2023)

| 논문에서 가져온 것 | 근거 표시 | 3판에서 반영한 곳 |
|---|---|---|
| 피드백은 문제 위치 + 개선 지시 | `[논문 직접·저자 공식 자료]` | `roles/v3/common_rules.md` '위치 + 행동', 수정안 8항목 |
| 피드백 → 수정의 반복, 멈출 조건 | `[논문 직접·저자 공식 자료]` | 조정 1회 한도 (`PROTOCOL_v3.md` 4단계) |
| 이전 출력과 피드백을 이어 붙여 같은 실수를 피함 | `[논문 직접·저자 공식 자료]` | 0단계 실행 전 읽기, 진행자가 반복된 실수를 범위 고정 때 미리 적음 |
| 진행자가 적용 뒤 원문과 글자 단위 대조 | `[응용 판단]` | `roles/v3/moderator.md` 4항 |
| 반론·유지 의견도 피드백 결과로 인정 ("수정하지 않음"도 결론) | `[응용 판단]` | `roles/v3/common_rules.md`, `moderator.md` 4항 |
| 단일 에이전트의 구체적 자기 피드백을 비교 조건으로 둠 | `[응용 판단]` (Self-Refine은 원래 한 모델이 자기 출력을 고치는 방법) | `PROTOCOL_v3.md` 후속 비교 조건 |

## 사람 피드백을 이용한 요약 학습 (Stiennon 외, 2020)

| 논문에서 가져온 것 | 근거 표시 | 3판에서 반영한 곳 |
|---|---|---|
| 사람의 실제 비교 판단이 기준이고 모델 판단은 그 예측 | `[논문 직접·원문 미확인(2차)]` | `expected_effect`와 `user_feedback`, `reader_observation`을 다른 칸에 둠 |
| 학습된 대리 기준을 지나치게 최적화하면 실제 사람 선호가 떨어짐 | `[논문 직접·원문 미확인(2차)]` | 에이전트 합의나 사용자 한 명의 취향만 따라가지 않고 최소 변경 유지 (`[미검증 예상]` 수준의 운영 원칙) |
| 반응이 오면 예상과 대조해 틀린 이유를 적고 적용 조건 갱신 | `[응용 판단]` | `PROTOCOL_v3.md` 7단계, `judgments.jsonl`. 모델 가중치 재훈련이 아님 |
| 사용자 한 명의 체감은 질적 피드백이며 넓은 독자 평가를 대표하지 않음 | `[응용 판단]` | 사용자 반응 칸, 읽은 순서·이전 노출 기록 |

## 인수인계서 v2에서 추가로 반영한 원칙 (논문 근거 아님)

- 같은 기반 모델로 돌린 세 에이전트의 합의는 독립된 판단이 아니다.
- 실패 사례 보존, 무조건적 규칙 금지.
- 단일 변경 실험과 결합 문단 개선, 새 소재 전이를 서로 같은 증거로 취급하지 않는다.
