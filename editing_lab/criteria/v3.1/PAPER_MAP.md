# 논문 적용 지도 3.1판

각 논문의 기준이 어느 역할, 어느 지시와 절차에 쓰였는지, 그리고 그것이 논문이 직접 말한 것인지 우리 편집에 응용한 판단인지를 한곳에 모은다.
기준 카드 원문: `../v3/` (검토자 카드는 각 에이전트가 직접 씀), `../v3/moderator_criteria_v3.md`. 읽은 범위의 근거: `../../sources/SOURCES.md`.

## 읽기 상태

| 논문 | 저자 공식 자료 (README 등) | 논문 본문 | 2차 자료 | 본문을 못 읽은 이유 |
|---|---|---|---|---|
| Flower & Hayes (1981) | 없음 (공식 저장소 없음) | **미확인** | 검색 요약 | JSTOR 유료, 네트워크 정책 차단 |
| DOC, Yang 외 (2023) | README, 코드 6개 파일 일부 | **미확인** | 검색 초록 | aclanthology.org·arxiv.org 차단 |
| SummEval, Fabbri 외 (2021) | README | **미확인** (서지 쪽수도 미확인) | 검색 요약 | aclanthology.org·direct.mit.edu 차단 |
| Self-Refine, Madaan 외 (2023) | README, 프로젝트 페이지 소스 | **미확인** | — | arxiv.org·proceedings.neurips.cc 차단 |
| Stiennon 외 (2020) | README | **미확인** | 검색 요약 | arxiv.org·proceedings.neurips.cc·openai.com 차단 |

그래서 현재 모든 논문 근거는 `[논문 직접·저자 공식 자료]` 또는 `[논문 직접·원문 미확인(2차)]`이며, `[논문 직접]`(본문 확인)은 하나도 없다.

## 역할별 적용

| 논문 | 적용 역할 | 논문에서 가져온 것 (직접) | 우리 편집에 옮긴 판단 (응용) | 적용 위치 |
|---|---|---|---|---|
| Flower & Hayes | 에이전트 1 | 목표의 위계, 검토 = 평가 + 수정, 목표는 쓰는 도중 바뀜 (`원문 미확인(2차)`) | 고정한 작성 목적을 평가 잣대로 씀, "목적 개선 / 매끄럽게 하기" 구분 | `roles/v3.1/reviewer_1_purpose_expression.md` 논문 기준 표, 절차 1단계 |
| (논문 없음) | 에이전트 1 | — | 조사·어순·호흡·어미 판단은 모두 `[응용 판단·한국어 표현]`, 근거 자료: 없음(모델 감각) | 같은 파일 한국어 표현 기준 표 |
| DOC | 에이전트 2 | 개요와 본문 분리, 순서 판정 부품은 원래 순서가 정답, 반복·선취 걸러내기, 인물 첫 등장 표시 (`저자 공식 자료`) | 필수 사실 = 개요, 두 자리에 같은 질문, 의도하지 않은 변화만 점검, 지시어·호칭의 첫 지점, `confounds` 기록 | `roles/v3.1/reviewer_2_order.md` 논문 기준 표, 절차 2~3단계 |
| SummEval | 에이전트 3 | 네 차원 이름과 차원별 주석 (`저자 공식 자료`), 네 차원 정의 (`원문 미확인(2차)`) | 원문 대비 편집본 비교, 9항목 판정표, 상쇄 금지, "나빠지지 않았는가" 관문, 거부권 아님 | `roles/v3.1/reviewer_3_fidelity.md` 논문 기준 표, 절차 2~5단계 |
| Self-Refine | 진행자 + 모든 검토자 | 피드백 = 문제 위치 + 개선 지시, 반복과 멈춤, 이전 출력 이어 읽기 (`저자 공식 자료`) | 수정안 8항목, 막연한 피드백 한 번 되돌림, 조정 1회, 글자 단위 대조, 유지·반론도 결과로 인정 | `roles/v3.1/common_rules.md`, `roles/v3.1/moderator.md`, 절차 0·2·4·5단계 |
| Stiennon 외 | 진행자 | 사람의 비교 판단이 기준, 대리 기준 과최적화 시 실제 선호 하락 (`원문 미확인(2차)`) | 예상과 반응을 다른 칸에, 반응 전 → 반응 후 판단 기록, 적용 조건 갱신(재훈련 아님), 최소 변경 유지 | `roles/v3.1/moderator.md`, 절차 6~7단계, `judgments.jsonl` |

Self-Refine과 Stiennon 연구를 담당하는 별도 에이전트는 두지 않는다.

## 이 지도로 말할 수 없는 것

- 어느 논문도 짧은 한국어 글에서 조사, 어미, 문장 배치, 정보 공개 시점이 독자에게 주는 효과를 입증하지 않았다.
- 논문 본문을 읽지 못했으므로, 본문에 있을 수 있는 반대 증거나 조건은 확인하지 못했다.
- 네트워크 설정에서 `aclanthology.org`, `arxiv.org`, `proceedings.neurips.cc`를 허용하면 네 논문의 본문을 확인해 이 지도를 고칠 수 있다.
  Flower & Hayes는 사용자가 가진 PDF가 필요하다.
