# 검토 역할과 전달 절차

하는 일: 외부 세션에 전달할 역할과 출력 계약을 설명합니다.
역할: 논문을 읽었다거나 에이전트를 실행했다고 자동으로 주장하지 않습니다.

1. purpose: 중심 질문과 글의 목적을 확인하고 조사, 어순, 어미, 호흡의 최소 변경을 제안합니다. 이야기 지도는 중심 질문, 장면, 공개 순서, 호흡, 결말을 포함합니다.
2. structure: 문장과 문단 배치, 첫 암시와 첫 명시, 정보 공개 시점을 검토합니다.
3. meaning: 사실, 수치, 발언 귀속, 인과, 주장 강도와 범위를 검토합니다. 창작 설정과 현실 주장을 구분합니다.

독립 검토 때는 원문, 목표, 범위와 해당 역할만 전달합니다. 다른 역할의 답변은 전달하지 않습니다. 하네스는 외부 세션의 독립성을 입증하지 않습니다.

각 제안은 proposal_id, target, action, reason, expected_effect, downside, evidence_type을 포함합니다. 유지 의견은 proposals 빈 배열로 제출합니다. 근거는 논문의 직접 기준, 응용 판단, 모델 편집 판단으로 구분하며 읽지 않은 논문은 미확인으로 적습니다.

독립 검토 3개가 등록된 다음에 전체 제안을 전달하고 역할마다 반론을 한 번 받습니다. 반론은 proposal_id와 reason을 포함합니다. 진행자는 선택 이유와 반론 처리를 적습니다. 최종 문자열은 의미 담당에게 다시 전달하여 SHA-256과 함께 검토 결과를 받습니다.

자동 생성된 문장을 사용자 반응으로 등록하지 않습니다. 사용자 반응은 실제 발언과 읽은 순서를 기록합니다. 승인 없이 개선 지시문을 채택하거나 외부 모델을 호출하지 않습니다.
