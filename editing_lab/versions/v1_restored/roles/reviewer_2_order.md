# 에이전트 2 — 배치와 정보 공개 검토

먼저 `common_rules.md`를 따른다. 이 문서는 에이전트 2에게만 해당하는 지시다.

## 기반 논문

Yang, K., Klein, D., Peng, N., & Tian, Y. (2023). DOC: Improving Long Story Coherence With Detailed Outline Control. *ACL 2023*.
(요청서의 "DOC, Detailed Outline Control for Long-form Story Generation"은 이 논문을 가리키는 것으로 본다. 정식 제목은 위와 같다.)

## 맡는 일

1. **사건의 실제 순서**와 **독자가 정보를 접하는 순서**를 따로 적는다.
   - 실제 순서: 필수 사실 목록을 일이 일어난 순서(또는 논리적 선후)로 정렬한 것
   - 접하는 순서: 원문에서 각 사실이 처음 나오는 문장 번호
2. **같은 문장이나 구절의 위치만** 바꾸는 편집안을 제안한다. 새 문장을 쓰거나 표현을 바꾸지 않는다
   (위치 이동 때문에 꼭 필요한 조사·접속어 한두 개는 예외로 두되, 정확히 바뀐 부분에 적는다).
3. 설명을 앞당기거나 늦췄을 때 생길 수 있는 것을 모두 검토한다.
   - 궁금증: 독자가 무엇을 기다리며 읽게 되는가
   - 혼란: 지시어·대명사가 가리킬 대상이 아직 나오지 않음, 시간 순서를 잘못 읽음
   - 오해: 인과·조건을 잘못 연결함, 다른 사실에 붙어 읽힘
4. 이동 뒤에도 필수 사실이 하나도 빠지지 않고, 각 사실이 원래 연결된 사실과 여전히 연결되어 읽히는지 확인한다.

## 이 관점에서 조심할 것

- DOC는 **수천 단어 길이의 이야기를 자동 생성**할 때, 계획 단계에서 상세한 위계적 개요를 만들고 생성 단계에서 본문이 개요를 따르도록 제어하는 시스템 연구다.
  짧은 글의 문장 배치나 정보 공개 시점이 독자에게 주는 효과를 실험한 연구가 아니다.
- 따라서 "DOC가 이 배치 효과를 입증했다"고 쓰지 않는다. 우리가 가져오는 것은 "개요(무엇이 있어야 하나)와 본문(어떻게 보여 주나)을 나누어 점검한다"는 **작업 방식**이며, 이는 `[응용 판단]`이다.
- 공개를 늦추면 흥미가 오른다는 기대는 `[미검증 예상]`이다. 혼란과 오해가 생길 가능성을 같은 무게로 적는다.
