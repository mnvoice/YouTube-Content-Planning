# 1판 복원본

준비 단계(2026-09-30)에서 검토 에이전트 세 개가 기준 카드를 쓸 때 읽은 판입니다.
진행자가 이 판을 제자리에서 고쳐 2판으로 만든 뒤 커밋했기 때문에, 1판은 저장소 기록에 파일로 남지 않았습니다.
에이전트 3이 수신 확인 보고(E-5)에서 이 점을 짚었습니다.

복원 방법: 2판 파일에 당시 한 번 반영한 수정(`logs/setup_2026-09-30.jsonl`의 `revise_once` 8줄)을 거꾸로 적용했습니다.
검증: 복원한 8개 파일의 SHA-256이 `logs/setup_2026-09-30.jsonl`의 `write_role_instruction_v1`·`write_v1` 줄, 그리고 `revise_once` 줄의 `sha256_before`와 모두 일치합니다.

이 폴더는 기록 보존용입니다. 현재 기준은 3판(`roles/v3/`)이며, 1판과 2판은 수정하지 않습니다.
