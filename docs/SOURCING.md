# 소재(아이템)는 어떻게 구하나

좋은 아이템은 세 가지를 모두 갖춥니다.

1. **수요**: 40~50대가 실제로 검색하고 궁금해한다
2. **공감**: "내 얘기다" 싶은 감정이 있다
3. **근거**: 공식 자료로 정확한 정보를 줄 수 있다

그래서 소재 발굴은 **발견 → 검증 → 확정** 세 단계로 진행합니다.

```
[발견]  ★ 잘 되는 채널 역기획 · 자동완성 · 댓글 · 커뮤니티 · 뉴스 · 시즌 캘린더
   ↓    → python -m ytplan benchmark → ideas --append (topic_bank.csv에 추가)
[검증]  네이버 데이터랩(40~50대 검색량) · 유튜브 아웃라이어 · 공식 출처 확인
   ↓    → python -m ytplan research / rank
[확정]  점수 상위 + 시즌 + 기둥 균형
        → python -m ytplan calendar → script
```

## 0. 가장 강한 소스: 이미 잘 되는 채널을 역기획하기

책상에서 떠올린 아이템은 밋밋하기 쉽습니다. 같은 시청자층에서 **이미 조회수가 나오는 채널**을 보면
시청자가 실제로 무엇에 반응하는지, 제목을 어떻게 달아야 누르는지가 데이터로 보입니다.

```bash
python -m ytplan benchmark                          # 40~50대 키워드 10개로 채널 15개 자동 발굴·분석
python -m ytplan benchmark --channel @핸들 --channel https://www.youtube.com/@다른채널   # 아는 채널 추가
python -m ytplan ideas --count 15 --append          # Claude가 히트 영상을 역기획해 새 아이템 15개를 뱅크에 추가
```

**핵심은 조회수가 아니라 '채널 평소 대비 배수'입니다.**

| 영상 | 조회수 | 그 채널 평소 조회수 | 배수 | 해석 |
|---|---|---|---|---|
| 구독자 100만 채널의 영상 | 30만 | 25만 | 1.2x | 채널의 힘. 우리가 따라 해도 안 나온다 |
| 구독자 5만 채널의 영상 | 30만 | 4만 | 7.5x | **주제와 제목의 힘.** 우리도 이 수요를 노릴 수 있다 |

그래서 `benchmark`는 채널마다 최신 영상 150개를 모아 중앙값을 '평소 조회수'로 두고,
그보다 2배 이상 나온 영상만 '히트'로 뽑습니다. (롱폼과 쇼츠는 따로 비교, 공개 14일 미만은 제외)

`output/benchmark_날짜-시간/benchmark.md`에서 볼 수 있는 것:

1. **벤치마크 채널 표**: 구독자, 평소 조회수, 주당 업로드 수, 롱폼 평균 길이, 쇼츠 비중 → 우리 채널의 운영 기준점
2. **히트 영상 TOP 30**: 여러 채널에서 반복해 터진 주제가 진짜 수요
3. **히트 제목 구조**: 숫자 목록·속마음 인용·후회·대상 지정 등 13가지 구조가 히트 제목에 평소보다 몇 배 더 쓰였는지(lift)
4. **히트 제목 핵심어**: 시청자를 누르게 만든 단어
5. **뱅크에 없는 히트 주제**: 우리가 놓친 아이템 후보
6. **수집 결과**: 채널별 성공·보류·실패·미실행과 사유, 빠진 채널이 결과에 주는 영향
7. **40~50대 근거**: 히트 영상 댓글에서 스스로 밝힌 나이 분포 (간접 근거. YouTube는 다른 채널의 시청자 연령을 공개하지 않음)

그다음 `ideas`가 이 결과를 Claude에게 넘겨 **수요는 빌리되 각도를 바꾼** 새 아이템을 만듭니다
(오해 바로잡기, 숫자로 계산해 보기, 두 선택지 비교, 먼저 겪은 사람의 후회 등).
`script`도 벤치마크 결과가 있으면 관련 히트 영상과 잘 먹힌 제목 구조를 참고해 제목과 오프닝을 씁니다.

역기획할 때 지킬 것:

- **제목·대본을 베끼지 않습니다.** 주제(수요)와 구조(형식)만 빌리고, 표현과 정보는 우리 것으로 씁니다.
- **방송사·뉴스 채널은 기본적으로 뺍니다.** 제작 규모가 달라 따라 할 수 없습니다. (`--include-broadcasters`로 포함 가능)
- **자극적인 사연·공포 마케팅이 터졌다면** '그런 불안이 있다'는 신호로만 읽고, 정확한 정보로 답합니다.
- 할당량: 기본 설정으로 1회 약 1,100 유닛 (하루 무료 1만 유닛). 결과는 24시간 캐시됩니다.
- 한 달에 한 번 다시 돌려 트렌드 변화를 봅니다.

## 1. 발견: 소재가 나오는 곳

| 소스 | 무엇을 얻나 | 방법 |
|---|---|---|
| 잘 되는 채널의 히트 영상 | 검증된 수요와 먹히는 제목 구조 | `python -m ytplan benchmark` (위 0장) |
| 유튜브 검색 자동완성 | 사람들이 실제로 치는 검색어 | `python -m ytplan expand "국민연금"` (키 불필요) |
| 인기 영상 댓글 | 시청자의 사연과 질문 = 공감 포인트 | `research`가 사연·질문 댓글을 자동으로 골라 줌 |
| 네이버 지식iN | 구체적인 질문 문장 | "퇴직 후 건강보험", "장기요양등급" 등으로 검색해 반복되는 질문 모으기 |
| 중년 커뮤니티 | 날것의 고민과 감정 | 네이버 카페(5060·은퇴·갱년기 카페), 82cook, 블라인드 40대 게시판, 브런치 에세이 |
| 뉴스 | 제도 변경·통계 발표 | `research`가 최근 30일 뉴스를 모음. 구글 알리미에 '연금', '건강보험료' 등록 |
| 정부 발표 | 새 제도와 정확한 수치 | 대한민국 정책브리핑, 매년 말 기획재정부 '이렇게 달라집니다' |
| 시청자 사연 모집 | 채널만의 진짜 이야기 | 설명란·고정 댓글에 구글폼 링크. 사용 동의 받고 개인정보는 지운 뒤 재구성 |
| 내 주변 | 가장 진정성 있는 소재 | 가족·친구·동료가 요즘 하는 걱정을 메모 |

> 커뮤니티 글을 **그대로 옮기지 마세요.** 공통된 고민을 뽑아 재구성하고, "이런 고민을 하시는 분들이 많습니다"처럼 전합니다.

## 2. 검증: 이 아이템, 될까?

### 네이버 데이터랩: 40~50대가 정말 검색하나

네이버 데이터랩 검색어 트렌드는 **연령 필터**(40~44, 45~49, 50~54, 55~59세)를 지원합니다.
한국 40~50대의 관심을 보기에 가장 직접적인 공개 데이터입니다.

- `research`는 모든 아이템을 기준 키워드('국민연금')와 함께 조회해서 **기준 대비 몇 배 검색되는지** 비교합니다.
  (데이터랩 값은 요청마다 최댓값을 100으로 둔 상대값이라, 같은 기준을 넣어야 여러 번의 조회를 이어 붙일 수 있습니다.)
- 최근 4주 / 이전 12주 비율로 **상승세**도 함께 봅니다.

### 유튜브 아웃라이어: 작은 채널도 터졌나

**구독자 수에 비해 조회수가 유난히 높은 영상**은 채널의 힘이 아니라 주제의 힘으로 조회수가 난 영상입니다.

- 구독자 1만 명 채널의 영상이 50만 회 → 50배 아웃라이어 → 주제 자체가 강하다
- 구독자 100만 명 채널의 영상이 10만 회 → 0.1배 → 채널 힘으로 본 것, 우리에겐 참고 안 됨

`research`는 최근 1년 인기 영상 25개의 배수를 계산하고, 상위 영상의 댓글에서 사연·질문을 뽑아 둡니다.
결과는 `output/research/<ID>.md`에서 확인합니다.

### 공식 출처: 정확하게 말할 수 있나

| 분야 | 1차 출처 |
|---|---|
| 연금 | 국민연금공단, 금융감독원 통합연금포털, 국민연금연구원 |
| 건강보험·요양 | 국민건강보험공단, 노인장기요양보험 |
| 건강 정보 | 질병관리청 국가건강정보포털, 각 학회 |
| 세금·상속 | 국세청 홈택스, 정부24 |
| 고용 | 고용노동부 고용24, 중장년내일센터 |
| 금융 사기·숨은 돈 | 금융감독원(파인), 경찰청 |
| 통계 | 통계청 KOSIS, 한국은행 경제통계시스템 |

공식 출처가 없는 아이템(소문, 민간요법, 특정 상품 후기)은 **정보형으로 다루지 않습니다.**

## 3. 확정: 순위와 캘린더

```bash
python -m ytplan rank            # 점수표: output/ranking.md, ranking.csv
python -m ytplan calendar --start 2026-10-01 --weeks 12 --days 화,금
```

점수 모델(`ytplan/scoring.py`):

| 항목 | 가중치 | 출처 |
|---|---|---|
| 검색수요 | 25% | 네이버 데이터랩 40~50대 검색량 (아이템 간 백분위) |
| 검증(아웃라이어) | 20% | 유튜브 구독자 대비 조회수 배수 |
| 공감 | 20% | 아이템 뱅크 수동 점수 |
| 정보 | 15% | 아이템 뱅크 수동 점수 |
| AI 제작 적합도 | 10% | 아이템 뱅크 수동 점수 |
| 시의성 | 10% | 시즌 + 최근 뉴스량 + 검색 상승세 |

- 건강(high)·금융(med) 등 틀리면 피해가 큰 YMYL 주제는 감점하고, 전문가 검수가 필요하다고 표시합니다.
- API 키가 없으면 데이터가 없는 항목은 빼고 계산합니다. 그래서 순위표의 **반영도**를 함께 봐야 합니다.
