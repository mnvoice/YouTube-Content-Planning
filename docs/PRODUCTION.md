# AI 제작 파이프라인과 지켜야 할 정책

## 1. 제작 흐름

```
기획안 생성 ─→ 사실 확인 ─→ 음성(TTS) ─→ 이미지 ─→ 편집·자막 ─→ 썸네일 ─→ 업로드 ─→ 쇼츠
python -m ytplan script     fact_checks 목록을 공식 출처에서 확인
```

| 단계 | 할 일 | 도구 예시 |
|---|---|---|
| 기획안 | 제목 5개, 썸네일 문구, 장면별 내레이션·자막·이미지 프롬프트, 사실 확인 목록 | `python -m ytplan script --topic M03` (Claude API), 또는 `--prompt-only`로 뽑아 claude.ai에 붙여 넣기 |
| 사실 확인 | 기획안의 사실 확인 체크리스트를 1차 출처에서 최신 기준으로 확인 | 공단·부처 누리집, 앱 |
| 음성 | 차분하고 신뢰감 있는 목소리, 약간 느린 속도 | 타입캐스트, 클로바더빙, ElevenLabs 등 |
| 이미지 | 같은 그림체로 장면 이미지 생성 (실존 인물·브랜드 없이) | 이미지 생성 AI (Midjourney 등) |
| 편집 | 자막 크게, 장면당 한 메시지 | Vrew, CapCut 등 |
| 썸네일 | 10자 안팎 큰 글씨, 강한 대비 | Canva, 미리캔버스 등 |

도구마다 **상업적 이용 조건**이 다릅니다. 유료 요금제에서만 수익 창출을 허용하는 경우가 많으니 약관을 확인하세요.

## 2. 40~50대가 편하게 보는 화면

- **자막은 크게**: 휴대폰에서도 읽히게, 화면 높이의 8~10% 정도. 흰 글씨 + 검은 테두리처럼 대비를 강하게.
- **말은 천천히**: 분당 약 280자(공백 포함) 기준. `script`의 분량 계산도 이 속도를 기준으로 합니다.
- **한 화면에 한 메시지**: 숫자·기준은 따로 크게 보여 주고 잠깐 멈춥니다.
- **배경음악은 작게**: 내레이션이 또렷하게 들리도록.
- **챕터 나누기**: 설명란에 타임스탬프를 넣어 필요한 부분만 다시 볼 수 있게.

## 3. 반드시 지켜야 할 정책

### YouTube

- **변경되거나 합성된 콘텐츠 공개**: 실제 사람이나 사건처럼 **보이는** AI 영상·이미지·목소리를 쓰면
  업로드할 때 YouTube Studio에서 공개 설정을 '예'로 해야 합니다.
  대본 작성·자막처럼 제작을 돕는 용도의 AI, 누가 봐도 일러스트인 그림은 대상이 아닙니다.
  → 그래서 이 도구는 이미지 프롬프트를 **일러스트 스타일**로 쓰도록 지시합니다.
- **수익 창출 정책(진정성 없는 콘텐츠)**: 2025년 7월부터 '반복적인 콘텐츠'가 '진정성 없는 콘텐츠'로 바뀌어,
  템플릿만 바꿔 대량으로 찍어 내는 영상은 수익 창출이 제한됩니다.
  주제마다 고유한 조사·사연·관점이 있어야 합니다. ([PLAN.md 6장](PLAN.md#6-ai-채널이-살아남는-차별화))
- **의료 잘못된 정보**: 보건 당국 지침과 어긋나는 치료법·효능을 말하면 안 됩니다.

### 한국 법·제도

- **AI 기본법(2026년 1월 시행)**: 생성형 AI 결과물 표시 의무는 주로 AI 서비스를 제공하는 사업자에게 있지만,
  시청자 신뢰를 위해 설명란에 'AI를 활용해 제작했습니다'를 넣는 것을 권합니다. (최신 시행령·가이드라인 확인)
- **광고 표시**: 협찬·제휴 링크가 있으면 공정거래위원회 추천·보증 심사지침에 따라 '유료 광고 포함'을 표시합니다.
- **금융**: 특정 종목·상품을 추천하거나 수익을 보장하는 표현은 쓰지 않습니다.
- **저작권**: 뉴스 사진·방송 화면·음원을 쓰지 않습니다. 통계와 제도는 출처를 밝힙니다.

## 4. 업로드 전 체크리스트

`script`로 만든 기획안 마지막에 같은 목록이 들어갑니다.

- [ ] 사실 확인 목록의 모든 수치·제도를 공식 출처에서 최신 기준으로 확인했다
- [ ] 건강·금융 아이템은 전문가 검수를 받았거나, 일반 정보임을 대본에 밝혔다
- [ ] 실제처럼 보이는 AI 이미지·영상을 썼다면 '변경되거나 합성된 콘텐츠'를 '예'로 설정했다
- [ ] 배경음악·폰트·이미지의 상업적 이용 라이선스를 확인했다
- [ ] 설명란에 참고 출처와 AI 활용 제작 안내를 넣었다
- [ ] 고정 댓글로 시청자 경험을 묻는 질문을 달았다 (다음 소재 수집)
